# <p align="center"> Food Healthy </p>

## O que é
Projeto para treino da linguagem Java para backend e uso de React Native para frontend. O objetivo é desenvolver um app de comida de uma loja de comidas saudáveis. Tendo os processos desde adicionar produto ao carrinho, até processar o pagamento em diferentes formas.

## Tecnologias utilizadas
- Java
- Spring Boot
- Sprint JPA
- Spring Security
- Lombok
